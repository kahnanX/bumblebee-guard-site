bumblebee-guard

A supply-chain guard for Hermes Agent. It wraps the Bumblebee scanner — exact-matching every installed package, MCP server and editor/browser extension against curated catalogs of known-compromised packages (plus OSV.dev advisories) — and makes the agent alert itself the moment a known-malicious package is present. Every number on this page comes from a real production deployment.

What a plugin does that a skill cannot

⚡ Self-alerting agent
  • A pre_llm_call hook injects a one-line supply-chain alert the instant curated findings exist — before the model answers anything else.
  • Zero cost when clean: no injection, no tokens, no latency. Rate-limited to once per hour.
🔎 Full runtime surface
  • Tools: bumblebee_guard_scan / _status / _diff (baseline diff of findings).
  • /bumblebee slash command in any chat.
  • Bundled triage skill: confidence classes, OSV alias dedup, documented false-positive pattern.

Try it

hermes plugins install <owner>/bumblebee-guard
hermes plugins enable bumblebee-guard
# then, in any chat:
/bumblebee scan      # full read-only sweep (no sudo, ~3 min)
/bumblebee status    # last results, catalogs, OSV count
/bumblebee diff      # what changed since your baseline
